二、规格逐条核对

左列为 TRAE_PROMPT.md 的条款，右列为实测结论与证据。

4.1 P0 · 上传与解析（loader / components）

规格要求结论证据
三格式上传、支持多选通过UPLOAD_TYPES = ["xlsx","xls","csv"]；合并 Tab 使用多文件上传
多 sheet 下拉切换通过单文件：选择 sheet；多文件：每个文件可多选 sheet
表头行号选择器，默认自动探测通过表头行号（从 1 开始） + 启发式探测；可疑时提示「疑似表头在第 N 行」
预览 20 行 + 共 N 行 × M 列通过PREVIEW_ROWS = 20；预览下方显示行列数
表头探测：非空 ≥2 且无重复值已确认偏差按确认的方案 2 放宽为「≥2 个不同非空值」，并增加下方 3 行列位置重合率 ≥80% 的形状校验；重复表头读入后自动改名 _2
「全部按文本读取」开关通过保留身份证号 / 工号前导零；测试 test_leading_zero_ids_stay_text
CSV 尝试 utf-8-sig / gbk / gb18030通过另有分隔符嗅探（, ; \t |）
失败给中文原因，不抛 traceback通过统一三段式 ExcelToolError
额外：.xls 真伪识别增强按文件头区分 xlsx / 旧版 OLE2 / 文本 CSV / HTML 假 xls，各自给专门提示

4.2 P0 · 按列拆分（splitter / split）

规格要求结论证据
选 1–2 列分组通过validate_columns；两列选重会提示换列
显示「将拆成 N 个文件」通过预估口径与真实分组一致（estimate_group_count）
生成 zip + 下载按钮通过to_zip_bytes，结果缓存于 session_state
文件名清洗 / 80 字符截断通过test_slash_and_illegal_chars 等 6 条拆分测试
空值分组命名「空值」通过纯空格也归入「空值」
重名追加 _2、_3通过忽略大小写比较，截断后仍不超长
>300 组拒绝执行通过MAX_GROUPS = 300，页面提前预警
zip 内含 _拆分说明.txt通过源文件、分组列、文件数、生成时间（UTF-8 BOM）

本次打包修掉的两个坑

  • developmentMode 顶掉端口：PyInstaller 下 Streamlit 误判为开发模式，报 server.port does not work when global.developmentMode is true；已在启动参数里显式关闭。
  • Windows 端口探测失效：允许重复 bind 同端口，导致 exe 和开发服务抢 8501；改为「先 connect 探测再 bind」。
单文件首次启动需解压依赖，约 10 秒；未做代码签名，Windows SmartScreen 可能提示「未知发布者」，选择「更多信息 → 仍要运行」即可。
